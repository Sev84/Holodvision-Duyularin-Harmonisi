# HARMONY SENSE

HARMONY SENSE is an accessible, multilingual social-content studio. It turns an image into colour analysis, notes, rhythm, haptic feedback and a screen-reader-ready description.

Languages: English, Turkish and Greek.

This `harmony-sense` branch is isolated from the repository's earlier HOLO-D-VISION work. The web application is static, installable as a PWA and uses on-device processing for its core experience.

## Responsible scope

- No diagnosis, identity recognition or clinical-therapy claim.
- No automatic social-media publishing.
- No embedded private API keys.
- The user confirms image rights and the final accessible description.

## Competition focus

The project supports equal digital participation through accessible content creation and aligns primarily with SDG 4, SDG 10 and SDG 11.
